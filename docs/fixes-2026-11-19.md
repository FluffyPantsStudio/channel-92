## Publication hygiene

- First-film data and paths come from `FLIX_FIRST_FILM` (`docs/first-film-replay.md`); tests that need it skip with a
  reason when it is unset. Lint fixtures are synthetic; the real ones are in the git-ignored `docs/private/`.
- "Test Person" in tests. `PROVENANCE.md` is generic with a module-to-spec table; the full version and
  `renames.md` are in `docs/private/`.
- Wheel: the build itself worked; the gap was that the graph name maps lived outside the package and an installed
  wheel silently lost them. They now ship in `atomic_flix/workflows/` (package data). `build` and `setuptools` are in
  the dev extra (the project venv lacked `build`, which is why `python -m build` failed there).

## Decided differently

- A1: "observed resident" means headroom has fallen by the load's own size since it was let start, less loads still
  to come; a load never seen to land stays counted until released (the safe side).
- A3/A10: a floor refusal sends the job back to the queue and ends only that host's worker, so another host may still
  take it if its own reading clears the floor.
- A7: `person` (Python API) is still taken, so stored books stay readable; it shows as "how it arrived not recorded".
- A14: SCAIL and Wan control clips keep their 32 step (their working sizes, 864x480 and 832x480, are not multiples
  of 128); the 128 rule applies to the LTX union-control video, which is what the integration note measured.
- B3: a relative graph path is now read from the film folder, not the working directory.
